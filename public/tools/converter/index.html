    사용 도움말

    저장한 파일은 어디에 쓰나요?
    • 챗봇에 넣을 때는 .md 파일을 사용하세요. 제목·본문·표를 읽기 쉽게 정리한 글 파일입니다.
    • 표는 원래 문서와 모양이 다를 수 있습니다. 특히 합쳐진 칸이나 숫자가 있는 표는 빠진 내용이 없는지 확인하세요.
    • PDF의 쪽 번호와 반복되는 머리말이 결과에 남을 수 있습니다. 필요한 본문이 빠지지 않도록 남겨 둔 것입니다.
    • 결과 한꺼번에 저장(.zip)을 누르면 변환한 문서와 점검 기록을 함께 받습니다. 점검 기록(.json)은 문제가 생겼을 때 담당자에게 보여주는 파일이며 챗봇에 넣지 않아도 됩니다.
    파일을 읽지 못했을 때
    • 한글 파일(.hwp)이 안 열리나요? 한글 프로그램에서 문서를 연 뒤 파일 → 다른 이름으로 저장을 누르세요. 파일 형식에서 HWPX를 선택해 저장한 파일을 다시 넣으세요. 파일 이름의 끝부분만 바꾸면 안 됩니다.
    • PDF 글자를 읽지 못하나요? 종이를 스캔한 PDF는 글자가 사진처럼 들어 있어 이 도구로 읽지 못할 수 있습니다. 문서 작성자에게 한글·워드 원본을 요청하세요. 원본이 없으면 PDF 프로그램의 문자 인식(OCR) 기능으로 처리한 파일이 필요합니다. 방법을 모르면 자료 담당자에게 요청하세요.
    • 메모장 파일(.txt)의 한글이 깨지나요? 메모장에서 원래 파일을 열어 한글이 정상인지 먼저 확인하세요. 정상이라면 파일 → 다른 이름으로 저장 → 인코딩: UTF-8로 저장해 다시 넣으세요. 원래 파일도 깨져 보이면 작성자에게 정상 파일을 요청하세요.
    • 워드 파일(.doc)이 안 열리나요? Word에서 파일 → 다른 이름으로 저장 → Word 문서(.docx)로 저장한 뒤 다시 넣으세요.
    • 버튼이 작동하지 않나요? Microsoft Edge 또는 Google Chrome에서 화면을 새로고침(F5)한 뒤 다시 해 보세요. 계속 안 되면 오류 문구와 점검 기록을 도구 담당자에게 전달하세요.
