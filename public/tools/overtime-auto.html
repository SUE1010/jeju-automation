계산 엔진(파이썬) 불러오는 중… 처음에는 10~30초 걸립니다.

📋 사전 작업 — 서식파일에 먼저 해두셔야 하는 일입니다.

  1. 시간입력 시트 입력소속 · 등급 · 성명 · 생년월일 · 근속년수를 입력해야 합니다
  2. 공무직 이름별 시트 생성서식의 '홍길동' 시트와 같은 형식으로 사람마다 시트를 만들고, 부서명(H3) · 이름(I3) · 생일(J3, 'mm/dd 형식)을 입력해야 합니다
  3. 이름 시트는 반드시 같은 파일 안에서 복사한셀·리브레오피스에서 시트를 복사하면 수식이 #REF! 로 끊어지고, 엑셀에서 '새 통합 문서'로 복사하면 다른 파일을 참조하게 됩니다. 실행할 때마다 표준 수식으로 되돌리고 로그에 빨간 글씨로 알려드립니다

선택 사항

공휴일 (대체공휴일 포함)

월을 고르면 주말·공휴일·대체공휴일이 자동으로 체크됩니다. 날짜를 누르면 넣고 뺄 수 있습니다(임시공휴일 등).

공휴일대체공휴일직접 지정토요일일요일

교육 참여 기간

근무상황내역에 '교육' 종별이 없어 직접 적습니다. 한 줄에 한 건씩 「이름 시작일 ~ 종료일 종료시각」. 예) 홍길동 2026-06-11 ~ 2026-06-12 17:00 → 6/12 17시 이후만 인정. 종료시각을 안 적으면 18:00.

소정근로시간 계산 범위

전월·익월에 걸친 주(예: 1주 = 전월 말~이번 달 초)의 평일을 넣을지 정합니다.

출근일수

저장 폴더

비워 두면 브라우저의 다운로드 폴더에 저장됩니다.

지정 안 함 (다운로드 폴더)

이 브라우저는 폴더 지정을 지원하지 않습니다. 크롬이나 엣지에서 열면 폴더를 고를 수 있습니다.

항상 자동으로 적용됩니다

· 서식 점검 — 지워진 수식·잘못된 등급을 찾아 되살립니다
· 지급시간 한도 점검(넘으면 경고) — 1일 4시간 / 1주 12시간 / 1달 25시간
· 주차별 배경색 — 2주·4주 행
· 야간가산 열(L·N·O) 수식 채우기
· 시간입력 시트의 빈 직원행·중복 성명 정리
